计算机的计算方式

例子1：计算 14+(-21)

1. 补码+补码

0000 1110
1110 1011
----------
1111 1001  = -7（补）

2. 补码->反码
# 正数：补码=反码=原码
# 负数：反码=补码->-1

1111 1001 = -7（补）
1111 1000 = -7（反）

3. 反码->原码
# 正数：补码=反码=原码
# 负数：反码=标志位不变，其他取反

1111 1001 = -7（反）
1000 0111 = -7（原）

例子2：计算 14-(-21) = 14 + 21

1. 补码+补码

0000 1110
0001 0101
----------
